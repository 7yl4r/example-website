# Quarto Website Template


This is a template for creating Quarto-powered websites.

## Usage
1. "use this template" >> "create new repository"
2. !!! check "include all branches"
3. name repo & create
4. click cog in top right "about" section
5. check "use your github pages website"
6. edit files & github action to will deploy it
    1. blog pages in `/articles/` directory.
    2. images should be uploaded to `/static/img/`


## Technical Details
Built using Quarto Docs on "Creating a Blog"[^1]
